# طُمُوح | TMoh — الإصدار 4.0

## الملفات
index.html, app.js, style.css, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png  ← ترفع على GitHub Pages
worker.js  ← يُنشر على Cloudflare Workers (وسيط المساعد الذكي)
supabase/schema.sql  ← مخطط قاعدة البيانات وسياسات RLS (لم يُربط بالواجهة بعد)

## التشغيل
افتح index.html، أو: python -m http.server 8000 ثم http://localhost:8000 (الـ Service Worker يحتاج http وليس file://).

## المساعد الذكي (Cloudflare Worker + Gemini)
اتبع الخطوات في أول worker.js. نقاط مهمة:
1. المفتاح GEMINI_API_KEY يُحفظ كـ Secret في Cloudflare فقط.
2. ALLOWED_ORIGIN = رابط موقعك على GitHub Pages.
3. الـ Worker يرفض الطلبات ما لم تربط Rate Limiting binding باسم RL و/أو KV باسم KV.
4. ضع رابط الـ Worker في CONFIG.AI_URL أعلى app.js. صفحة المساعد تعرض حالة الخدمة (متصل / غير متاحة).
الحد هنا لكل عنوان IP. الحد لكل حساب يحتاج ربط Supabase.

## قاعدة البيانات (Supabase)
1. أنشئ مشروعًا، ثم الصق supabase/schema.sql في SQL Editor وشغّله.
2. بعد تسجيل حسابك عيّن نفسك مديرًا بالسطر الأخير في الملف.
3. الواجهة الحالية لا تتصل بـ Supabase بعد: البيانات محلية (localStorage + IndexedDB للصور).

## إضافات الإصدار 4.0
- قسم «رحلتي نحو حلمي»: خطوات صغيرة قابلة للتأشير، ملخص أسبوعي، وسجل تقييم اختياري بعد جلسة المذاكرة.
- قسم «المكافآت»: نقاط مشتقة من نشاط الطالب المسجل وصناديق بمستويات ثابتة، وهدايا أنشطة قصيرة حسب الهواية؛ لا يوجد دفع أو سحب عشوائي.
- تخصيص الهواية وطريقة التعلم من الإعدادات، وتمرير التفضيلات للمساعد عند تفعيله.
- ترحيل تلقائي لملفات الطلاب القديمة مع قيم افتراضية للحقول الجديدة؛ وتدخل الحقول الجديدة ضمن النسخ الاحتياطي.

## ما يعمل الآن
مؤقت دقيق (لا يحسب وقت إغلاق الصفحة، ويقسم الجلسات عند منتصف الليل) • بنك أخطاء بصور في IndexedDB • تراكمات بخطة حسب وقتك اليومي • نظام اختبارات من بنك أسئلة تضيفه أنت (اختيار من متعدد/صح وخطأ، مؤقت، تصحيح تلقائي، سجل، نقاط ضعف) • نسخ احتياطي كامل بإصدار وفحص بنية • تقرير أداء للطباعة/PDF • تذكير بالمهام • PWA يعمل بدون إنترنت.

## حدود مهمة يجب معرفتها
- البيانات ما زالت محلية على الجهاز والمتصفح؛ لا توجد حسابات سحابية أو مزامنة بين الأجهزة حتى يتم إعداد Supabase وربطه واختباره.
- المكافآت الحالية أنشطة داخلية بسيطة وليست قسائم أو هدايا مادية.
- تقييم المشاعر اختياري ويُستخدم للتخصيص فقط، وليس تشخيصًا طبيًا أو نفسيًا.

## ما لا يعمل بعد
حسابات Supabase والمزامنة ولوحة الإدارة • دروس المناهج الرسمية (تُستورد من ملف JSON) • أسئلة رسمية جاهزة • ملفات PDF للدروس.
